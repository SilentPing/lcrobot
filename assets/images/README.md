# Logo Files for PDF Reports

This directory should contain the following logo files for the PDF reports:

## Required Logo Files:

1. **LGU Botolan Logo**
   - File: `lgu_botolan_logo.png`
   - Location: Left side of PDF header
   - Recommended size: 25x25 pixels
   - Format: PNG with transparent background

2. **LCRO Logo**
   - File: `lcro_logo.png`
   - Location: Right side of PDF header
   - Recommended size: 25x25 pixels
   - Format: PNG with transparent background

## Fallback Text:
If the logo files are not found, the system will display fallback text:
- Left side: "LGU BOTOLAN"
- Right side: "LCRO"

## Instructions:
1. Place your logo files in this directory
2. Name them exactly as specified above
3. Use PNG format for best quality
4. Ensure logos have transparent backgrounds
5. Recommended size is 25x25 pixels for optimal display
